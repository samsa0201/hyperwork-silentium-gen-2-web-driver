# Captures

Lưu dữ liệu bắt được từ thiết bị thật ở đây, đặt tên theo kết nối, ví dụ:

- `receiver-usb-a.json`, `receiver-usb-c.json`, `wired.json` — export từ `tools/hid-probe`.
- `*.pcapng` — USBPcap/Wireshark khi chạy công cụ firmware chính hãng (ghi chú thao tác tương ứng trong file `.md` cùng tên).

Không commit file firmware của hãng.
