Silentium Gen 2 — cập nhật firmware qua Bluetooth

Thay cho BLEOTATool (chỉ có trên Windows). Dùng Web Bluetooth, chạy trên Chrome/Edge desktop (macOS, Windows, ChromeOS) qua http://localhost hoặc HTTPS. Giao thức: Nordic Secure DFU (service 0xFE59) trên chip OnMicro OM6621, lấy từ việc dịch ngược công cụ chính hãng — xem docs/OTA.md.

1. Chọn file firmware

File MS01G2UPDATE.zip nằm trong gói MS01_G2_update.rar do HyperWork phát hành (giải nén file .rar trước).

Chưa chọn file.

2. Đưa chuột vào chế độ ghép nối Bluetooth

  1. Gạt chuột sang chế độ Bluetooth.
  2. Giữ nút kết nối khoảng 3 giây cho tới khi chuột vào chế độ ghép nối.
  3. Không ghép nối chuột với máy tính trong cài đặt Bluetooth của hệ điều hành.
  4. Sạc chuột đủ pin; không tắt chuột hay đóng tab trong lúc cập nhật.

3. Kết nối

Hộp chọn thiết bị liệt kê mọi thiết bị Bluetooth đang quảng bá; chọn đúng tên chuột. Web Bluetooth không cho biết MTU — nếu gói lớn bị lỗi, chọn lại 20 byte.

Chưa kết nối.

4. Cập nhật
